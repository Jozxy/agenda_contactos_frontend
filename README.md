# 📇 AgendaApp Frontend

Aplicación web de gestión de contactos desarrollada con Vue 3, Pinia y Vue Router. Diseñada para ser desacoplada y consumir cualquier backend PHP que respete el contrato de API definido.

## 🚀 Tecnologías
- **Vue 3** (Composition API + `<script setup>`)
- **Pinia** (State Management)
- **Vue Router** (Navegación y Guards)
- **Vite** (Build Tool & Dev Server)
- **CSS Nativo** (Variables, Flexbox, Grid)
